This directory holds ENCRYPTED wallet keystore blobs (keystore/) and a managed_wallets export (managed_wallets.json). It does NOT contain the KEK passphrase (LAUNCHER_KEK_PASSPHRASE) -- that must be stored SEPARATELY, never alongside this backup. See docs/wallet-pool-plan.md Phase 4 for the restore runbook (decrypt one known wallet and confirm the derived address before trusting the pool).
