# Frontend — `frontend-react/` (React SPA)

File-level map of `frontend-react/src/`. Stack: React 19 + TS + Vite, RTK Query + Redux Toolkit, React Router 7, Tailwind 4, lightweight-charts.
Dev: `npm run dev` (:5173, proxies `/api` → `:8081`). Build: `npm run build` (`tsc && vite build`).
Chart logic explainer: `@project_plans/token-analysis/token-history-chart-functionalities.md`, swing: `@project_plans/token-analysis/swing-detection-logic.md`.

## Entry & routing
- `main.tsx` — React root + Redux Provider.
- `App.tsx` — `BrowserRouter`; all pages nested under `<AppLayout>`. Routes: `/`, `/dashboard`, `/tokens`, `/token/sync`, `/transactions`, `/analysis/{general,swing-detection}`, `/profiles/{mine,other}`, `/strategies/{tpsl1,tpsl2}`, `/strategies/grouped-sweep-tpsl1`, `/strategies/grouped-sweep-tpsl2`, `/settings`, `*`. Every route page is **code-split** via `React.lazy` (named exports mapped to `default` in each `lazy()` call) so heavy tables/charts/sweep stay out of the initial bundle; `<Routes>` is wrapped in one `<Suspense fallback={<SuspenseFallback/>}>`. Layout/nav/providers + the root `RouteErrorBoundary` load eagerly.

## Layout — `components/layout/`
`AppLayout.tsx` (Header + `<Outlet>`, the Outlet wrapped in a page-level `RouteErrorBoundary` so a page throw degrades to a fallback card while the nav stays live), `Header.tsx` (nav, live-mode toggle, SOL/USD fetch→PriceUnitContext, PriceUnitToggle, TimezoneSelect), `PageShell.tsx`.

## Error boundaries — `components/ui/ErrorBoundary.tsx`

`ErrorBoundary` (class) catches descendant render throws (e.g. a null in a live trade tick) instead of unmounting the tree; resets on `resetKeys` change (auto) or the fallback's "Try again" (manual). `RouteErrorBoundary` wraps it with `useLocation` so the path is the reset key → navigating away from a broken page recovers without a reload. Two instances: `App.tsx` wraps `<Routes>` (`variant="root"`, full-screen catch-all for Header/layout/provider crashes); `AppLayout` wraps `<Outlet>` (`variant="page"`, contained card under the live nav).

## Components — `components/`
- **`ui/`** reusable primitives: `Button`(+`ButtonGroup`), `Badge`, `Modal`(+`InlineAlert`), `Input`/`Textarea`, `Checkbox`, `Switch`, `Select`, `Tabs`, `PriceUnitToggle`, `TimezoneSelect`, `StatusButton`, `AddressDisplay`, `StatCard`, `NavDropdown`, `InfoTooltip`, `VisibilityToggleButton`, `SuspenseFallback` (lightweight route-level lazy-load fallback used by `App.tsx`), `ProgressBar` (honest determinate bar + optional Cancel — shared by sim + sweep; `processed/total·%` with comma-grouped counts, plus an optional second line — remaining count, a ticking `~ETA remaining`, and elapsed — when the caller passes `etaMs`/`elapsedMs`; `done?: boolean` renders a muted completed row with checkmark + full bar, no cancel/ETA, for use by sweep phase history). All compose via `cn()` (`lib/cn.ts`).
- **`table/` DataTable** — generic `DataTable<R>`: client- or server-side mode, pagination (`Pagination.tsx`), sort, per-column filter (`numericFilter.ts`), column visibility (persisted by `tableId` prop into the shared `mt:table.cols` map — see `lib/storage`), selection, search, **memoized rows**, pure-CSS `:has()` hover. Cells: `DateCell`, `RelativeTimeCell`, `AgeCell` (subscribe `useNow`). Types in `types.ts` (`ColumnDef`, `TableQuery`, `SortCtx`). `ColumnDef.renderHeader(SortCtx)` replaces the default label/sort-arrow with custom header content that can drive the table's sort by any key — incl. hidden (`defaultVisible:false`) sort-only columns, since sort resolves off the full `columns` list, not just visible ones. Optional `groupLabels` prop (group key → label) renders a non-sticky spanning banner row over each `group` run of columns (e.g. Entry/Exit on the grouped-sweep tables).
- **`dashboard/`** — Token-creation-bias panels: `creationStats.ts` (response/args types mirroring `/api/tokens/creation-stats` + pure helpers: `metricValue` null-on-zero-coverage, `heatColor` scale, DOW/HOUR axes, segment/metric/bucket/range option lists), `CreationHeatmap.tsx` (`React.memo` pure-CSS-grid 7×24 day×hour fold; count view = share-of-total shade, outcome views = rate shade), `CreationTrendChart.tsx` (`React.memo` lightweight-charts histogram; buckets are pre-tz-shifted naive wall-clock parsed as UTC so the UTC-formatting axis renders them verbatim — no double shift; chart created once, only series data swapped).
- **`tokens/`** — `tokenColumns()`, `priceCells.tsx` (factories that bake formatter once, ignore rate ticks), `TokenDetailPanel`, `TokenTradeChart`, `FilterPanel` + `filters.ts` (`TokenFilters`, localStorage).
- **`token-price-chart/`** — lightweight-charts wrapper (`TokenPriceChart`). Transforms `chartBars.ts`, `swingOverlay.ts`, `chartViewport.ts` (localStorage per mint), `chartTimezone.ts`. Plugins: `walletMarkersPlugin`, `chainHighlightPlugin`, `rangeSelectPlugin`. Tooltips: Bar/Swing/WalletMarkers/ChainHighlight/RangeSelect. **Perf:** `subscribeCrosshairMove` writes the latest tooltip snapshot into a ref and flushes all tooltip setters once per `requestAnimationFrame` (coalesced) so hovering costs ≤1 render/frame, not 1/pixel; `ChartToolbar` memoizes its price/vol formatters by `priceUnit`. The plugin-reapply effects (chain highlight, range select) key on `style`/grouping (which recreate the series+plugin) and intentionally exclude `bars` (a per-tick bars change reuses the series, so re-running would only repaint). `index.ts` exports `aggregateTradesToBars`, `barsTo{Line,Candle}Data`, `swingsToColoredLineData`, etc.
- **`analysis/`** — `swingColumns`, `swingChainColumns`, `analysisColumns`/`creatorColumns`, `swingParams.tsx`, `swingFilter.ts`, `swingChains.ts`.
- **`tpsl1/` & `tpsl2/`** (near-identical) — `ruleColumns`, `tableColumns` (`simColumns`/`matchedColumns`/`positionColumns`), `RuleFormModal`, `SimSummaryCard`, `TokenInspectModal`, `utils.ts`.
  - **`RuleFormModal` per-group locks**: when editing, fields are grouped (`fingerprint`/`sizing`/`exit`, plus `entry` in tpsl2) by `LockGroup`, each locked by default with its own 🔓/🔒 toggle to prevent accidental edits. A *live* rule (`is_active || open_positions > 0`) freezes every group except `sizing` (buy amount + concurrency caps — the hot knobs safe mid-run); those toggles are disabled. `buildUpdatePayload(form, unlocked)` emits keys for **unlocked groups only**, so a locked param can't be zeroed (backend merge leaves it untouched). On the rule table, Edit is always enabled (so hot params stay reachable) but Delete is disabled while live.
- **`transactions/`** — `tradeColumns(price)`, `tokenTradeColumns(price)`. **`wallet/`** — `walletColumns(price)`.
- **`sweep/`** — sweep page helpers (shared by the flat + grouped pages). `buildSweepColumns(paramKeys)` (param cols derived from run params + metric cols: win%, total/expectancy/median PnL, profit factor, holding, exit mix; a plain ordered array like `tokenColumns` — column order = array order (params follow the page's `paramKeys`, metrics follow the literal), grouping = each col's `group` (params tagged entry/exit by prefix); param keys prefixed `p_<k>`), `types.ts` (`SweepRunRecord`, `SweepResultRecord`). Grouped-sweep additions: `groupedTypes.ts` (`GROUP_FIELDS`/labels, `TPSL2_AXES` editable-axis defs mirroring backend defaults, run/group/result + start-arg types), `groupColumns.tsx` (`buildGroupColumns(paramKeys)` — fingerprint-key chips, the Tokens/Fired/Best-expectancy metric columns, then one sortable + numeric-filterable column per swept param read from `best_params`, `group`-tagged entry/exit for the divider + spanning banner; high-leverage knobs default-visible, the rest behind the Columns toggle), `SweepConfigForm.tsx` (the config form; parses the comma-separated grid, projects combo count vs `MAX_COMBOS`).

## State, services, hooks
- **`store/`** — `index.ts` (store; RTK Query 5min cache, `refetchOnMountOrArgChange:false`), `apiSlice.ts` (queries: `getTokens`, `getTokensPage`, `getTokenDetail/Trades`, `getWalletHoldings/Holding/Prices`, `getSolPrice`, `getLiveMode`, `getSettings`, `getProfiles` (tracked-wallet markers; `Profiles` tag, 120s retention — shared by Swing + Sync), `getStrategy{Matched,Simulate,PaperResult}` (per-rule, 60s retention, `StrategyResult`/`StrategyPaper` tags; `getStrategySimulate` resolves to `SimulatedTokenResult[] | {cancelled:true}`; matched/simulate take optional `from`/`to` on `StrategyRuleArg` appended as `?from=&to=` via `withAnalysisRange` — part of the cache key, ignored by paper-result), `getGroupedSweep{Runs,Groups,Results}` (grouped param-sweep, 120s retention; runs tagged `GroupedSweep`; all keyed by `strategyId`, results fetched lazily on group drill-in); mutations: `buyToken`, `sellToken`, `setLiveMode`, `updateSettings`, `startGroupedSweep` (DB-range grouped sweep, invalidates `GroupedSweep`), `deleteGroupedSweepRun`/`pruneGroupedSweeps` (delete one run / prune runs before a cutoff; both invalidate `GroupedSweep`)), `strategyResultCache.ts` (imperative `fetch{Matched,Simulate,PaperResult}Cached` + `invalidateStrategyResult` — dispatch→unwrap→unsubscribe so the strategy pages route their toggle-driven reads through the RTK cache), `swingDetectionSlice.ts`, `syncTokenSlice.ts`.
- **`services/`** — `api.ts` (standalone fetch helpers: tpsl{1,2} CRUD/lifecycle/sim/positions, `cancelSimulation` + `cancelGroupedSweep`, swing detect, profiles/tags, `syncToken` w/ progress), `sse.ts` (single shared `EventSource` to `/api/stream`; `connectTradeStream`, `connectTokenCreatedStream`, `connectPaperTestStream`, `connectSimulationFinished`, `connectSweepFinished`, `connectTpsl{RulesChanged,PositionsChanged}`, raw `sseSubscribe`), `config.ts` (`API_BASE`, `POLL_INTERVAL_MS`, `FALLBACK_POLL_INTERVAL_MS`).
- **`context/`** — `AppProviders`, `PriceUnitContext` (`usePriceUnit`: unit + usdRate, localStorage↔backend), `TimezoneContext` (`useTimezone`), `BackgroundJobsContext` (app-wide registry of long-running jobs — grouped sweep + rule sims — seeded from `/api/jobs/status`, kept live by one set of session-long SSE subs; **split into two contexts** so a progress tick re-renders only state consumers: stable **actions** `useBackgroundJobActions` (`markStarting`/`cancel`) the strategy pages consume tick-free + **state** `useBackgroundJobsState` (`jobs`/`isRunning`) the `components/layout/BackgroundJobsIndicator` consumes. Each job carries an ETA baseline (`firstSeenAt`/`firstSeenProcessed`, stamped on first observation) so the indicator can derive an average-throughput ETA that stays honest for jobs recovered mid-run from the status snapshot; the indicator runs one local 1s timer — gated on `jobs.length>0` — to tick the ETA/elapsed countdown between sparse SSE frames. **Multi-phase sweep bars**: `BackgroundJob` carries `phases: Map<string, PhaseProgress>` + `activePhase`; each `sweep_progress` SSE frame carries a `phase` tag (`"coarse"` / `"sweep"` / `"saving"`) that `upsert` routes into the map, marking the prior active phase `done: true` when a new one arrives. `BackgroundJobsIndicator` renders one `ProgressBar` per phase (done phases shown muted with a checkmark); falls back to a single bar when `phases` is empty (status-recovery seed or simulations)).
- **`hooks/`** — `useNow(granularityMs)` (shared clock, one interval/granularity, pauses when hidden), `useVisiblePolling`, `useTradeStream`, `usePolledRules`, `useRulePositions`, `usePriceDisplay` (rate folded out in SOL mode), `useWalletPriceDisplay`, `useLocalStorage(key, initial)` (persisted `useState`, lazy-read + write-on-change; delegates to `lib/storage`).
- **`types/index.ts`** — `TokenRecord`, `TokenDetailRecord`, `TradeRecord`, `RuleRecord`, `RulePositionRecord`, `WalletHolding`, `WalletPrice`, `LiveTrade`, `SwingDetectionResult`, paper/sim shapes, `WalletProfile`/`WalletEntry`/`WalletProfileTag`.
- **`utils/`** — `format.ts` (formatDecimal, formatPrice, formatCompact, formatAge, formatUsd, color classes), `date.ts` (timezone-aware), `addressLinks.ts` (Solscan/GMGN). `date.ts` also exports `datetimeLocalToUtcWallClock(value, tz, bound)` — converts a picker wall-clock in the selected project tz to the exact UTC wall-clock the backend's `parse_dt` expects (DST-aware: probes the offsets straddling the typed day; inclusion-safe `lower`/`upper` tie-break inside transitions). `getTokensPage` calls it on the datetime-range `f_*` filters. **`lib/`** — `cn.ts`, `tpslParamHelp.ts`, `storage.ts` (the single localStorage layer: `STORAGE_KEYS` registry — all keys namespaced under `mt:` — `getJSON/setJSON/getString/setString/remove`, and the `mt:table.cols` column-visibility map via `get/setTableCols(tableId)`. Every persister reads/writes through here. On import, `cleanupLegacyStorage()` purges the old flat pre-namespace keys (`*_cols`, `sweep_cfg_*`, singletons) once so the store only holds the `mt:` set).

## Perf patterns (CLAUDE.md "Definition of done" — verify no extra re-render on rate/trade ticks)
- Column defs + price formatters memoized; cells read context directly (no prop re-thread); rate folded out in SOL mode.
- Shared `useNow` clock; cells bail when coarsened snapshot unchanged.
- Single SSE `EventSource` multiplexes all events; rules/positions = SSE refetch + debounce + visibility-gated fallback poll.
- RTK Query structural sharing + `keepUnusedDataFor` 5min + `skipPollingIfUnfocused`; optimistic mutations.
- localStorage (all via `lib/storage`, keys namespaced under `mt:`) caches filters, timezone, price unit, chart prefs, sweep-form config, and column-visibility (one shared `mt:table.cols` map keyed by `tableId`, not a key per table).
